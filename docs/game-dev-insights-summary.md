# 게임 개발 인사이트 정리 (저세상개발자 + MGD 채널, 2026-10-13 기준)

project-youtube-insight DB에 쌓인 게임 개발 관련 영상 16건을 주제별로 정리한 문서. 다른 게임 프로젝트에서 적용 여부를 검토할 때 참고용.

## 레벨 디자인 / 튜토리얼

- **레벨이 곧 설명서**: 훌륭한 튜토리얼은 텍스트 설명이 아니라, 안전한 환경에서 하나씩 학습하도록 배치된 레벨 구조 자체로 규칙을 가르친다 (슈퍼마리오 1-1 분석).
- **맵/랜드마크 유도**: 어디로 가야 할지 명시적으로 알려주지 않고도, 눈에 띄는 랜드마크와 보상 배치만으로 의도한 경로를 자연스럽게 걷게 만든다.
- **카메라는 레벨 디자인 도구**: 카메라는 캐릭터를 따라다니는 장치가 아니라 플레이어의 시야·정보 노출을 의도적으로 통제하는 도구로 쓰인다 (룩헤드 카메라, 비밀방 전용 카메라, 장애물 고정 카메라 등).

## 전투 / 조작감

- **소극적 플레이 방지**: '죽지만 않으면 되는' 소극적 플레이를 막기 위해 보상(회복)과 페널티(자기장 축소 등)를 동시에 설계해 적극적 전투를 유도한다.
- **조작감의 디테일**: 가속/감속 이동, 반대방향키 급정거, 버튼 세기에 따른 점프 높이, 버튼 떼면 빠른 하강, 러닝점프 보정 — 이런 세밀한 입력 보정이 "손맛"을 만든다 (슈퍼마리오 조작감 분석).
- **렉 컴펜세이션**: 네트워크 지연 보정은 "맞았는데 빗나감"보다 "숨었는데 맞음" 쪽 불만이 덜하다는 사용자 심리를 이용한 트레이드오프.

## 그래픽 / 최적화

- **노멀맵**: 지오메트리를 늘리지 않고도 조명 반응만으로 입체감을 만드는 가장 효율 좋은 그래픽 기법.
- **대규모 자연물(잔디 등) 최적화**: 컬링 + LOD + GPU 인스턴싱의 조합으로 달성, 단일 기술로는 안 됨.
- **복셀 지형**: 파괴/건축 가능한 지형의 핵심 표현 방식. 청크 분할 + 은면 제거 없이는 처리 부하로 실용화 어려움.
- **하늘/구름**: 스카이박스 + 워리 노이즈/펄린 노이즈 조합이 이미지 텍스처만 쓰는 것보다 훨씬 자연스럽다.
- **벡터 내적**: 시야각 판정, 이동 방향 판정, 조명(람베르트 반사) 계산까지 — 하나의 수학 개념이 엔진 여러 시스템의 공통 기반.

## 사운드

- **물리 기반 오디오**: 거리감쇠, 도플러 효과, 실내 반향, 장애물 폐색 — 화면 밖 상황도 청각으로 직관적으로 전달.
- **어댑티브 뮤직**: 곡의 완성도보다 "언제 자연스럽게 전환되는가"가 몰입감을 만든다 (이벤트별 악기 레이어 추가, 보스전 반복 가능한 전환 음악 등).

## AI 보조 개발 워크플로

- **엔진 선택 기준 변화**: AI 에이전트가 안전하게 읽고 고칠 수 있는 파일 포맷인가가 성능/생태계보다 중요해질 수 있다. Godot의 텍스트 기반 씬(.tscn)은 Unity의 바이너리/복잡한 YAML(.unity, .prefab)보다 AI가 직접 편집·검증하기 훨씬 안전하다.
- **LLM 에이전트 자동 플레이**: 기술적으로 가능하지만, 대화 기록 누적에 따른 비용 폭증과 목표 망각 문제가 실전에서 더 큰 병목.
