메이커 에반 | Maker Evan · 2026-10-05T00:00:00+00:00

바이브코더용 실전 배포 팁 7가지. 1)코드는 Cloudflare Workers, 파일은 R2, DB는 Neon Postgres+Hyperdrive (D1은 10GB 상한·단일쓰기큐·벡터검색 확장 열위라 비권장). 2)업로드 이미지는 화면 크기 기준으로 WebP 압축(가로1600/화질75, 10MB→127KB), 영상은 720p 재인코딩. 3)한글 폰트는 Pretendard+다이나믹 서브셋(영한 통일, 9단계 굵기, 7MB→조각당 20KB대). 4)AWS는 바이브코더에 위험 — 키 유출시 상한없는 과금폭탄(실제사례 5분만에 탈취·$2375 청구), Cloudflare/Neon 무료플랜은 초과시 요금 대신 '멈춤'. 5)목록용 썸네일은 화질·크기 크게 낮춰도 됨(가로400/화질60, 5KB). 6)Wrangler 등 CLI 필수설치 — AI가 대시보드 복붙 없이 배포·로그·DB 직접 처리. 7)CDN 붙이면 DB엔 파일명만 저장+CDN prefix는 환경변수+파일명에 해시로 캐시 무효화까지 같이 바꿔야 함.

인사이트 이 스택 추천은 '서버/DB/업로드 파일이 있는 서비스'를 전제로 한다 — 이 프로젝트(youtube-insight)처럼 정적 요약 페이지만 GitHub Pages에 올리고 DB는 로컬 SQLite로 자동화를 돌리는 구조엔 Workers/R2/Neon 이전이 불필요하다(해결할 문제가 없음). 다만 폰트 팁은 정확히 우리 공개 페이지의 실제 문제를 짚는다 — 지금 publish.py는 시스템 폴백 폰트(맥 산돌고딕/윈도우 맑은고딕)를 쓰고 있어 기기마다 다르게 보인다. Pretendard 적용이 이 프로젝트에 유일하게 바로 적용할 가치가 있는 팁.
